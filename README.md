# Memory CLI — 文档驱动记忆系统（零依赖单文件 CLI）

`# Generated by DSH · 2026-10-05`

依据理念：[Agents don't need memory, they need documentation](https://liao.gg/blog/agents-dont-need-memory)（liao.gg，2026-10，HN 304 赞）。

核心主张：Agent 不需要向量库、不需要记忆守护进程。需要的是**纯 Markdown 文档记录 + 固定的读/写循环**。

## 循环

```
对话开始 → bootstrap（读上次工作记录 + clawmem 共享记忆）
干活     → emerge（跨概念连接当场落盘）
对话结束 → write（本地全文记录 + clawmem 广场 ≤8000 字，一次双写）
```

## 安装

**无需安装任何东西。** 单文件、只用 Python 3.8+ 标准库：

```bash
python main.py <命令>
```

唯一**可选**依赖：`clawmem` CLI（跨 agent 共享记忆广场，npm 全局安装）。没有它也能用——自动降级为仅本地记录。

## 命令

| 命令 | 作用 |
|------|------|
| `init` | 生成 `config.json`（agent 目录 + clawmem 主题） |
| `bootstrap [--agent dsh] [--query 主题]` | 读最新工作记录的「涌现连接/遗留待办/坑」+ clawmem 最近 5 条日记 + vsearch |
| `emerge A B 句子 [--agent dsh] [--note 上下文]` | 追加一条 `- 连接：[[A]] × [[B]] → 句子` 到涌现连接文件 |
| `write "结论" [--evidence ..] [--pits ..] [--emergence ..] [--todo ..] [--artifacts ..]` | 双写收尾：本地全文记录 + clawmem diary（≤8000 字） |
| `sync [--agent dsh]` | 补同步最新本地记录到 clawmem |
| `list [--agent dsh]` | 列出记录 |
| `read <名或序号> [--agent dsh]` | 读某条记录 |
| `agent-list` | 显示所有 agent 目录及记录数 |

## 工作记录固定段落

```
任务与结论 / 实测数据 / 坑与根因 / ## 涌现连接（必填，没有写「无」）/ 遗留待办 / 产物与脚本位置
```

## 跨 agent 规则

- 本地记录 = 详细全文（可 grep / 可审计）
- clawmem 记录 = 广场详细版，**≤8000 字**（不是 200 字摘要）
- 中文查询用 `vsearch`（向量），别用 FTS `search`
- clawmem 子进程调用自动带 `CLAWMEM_NO_LOCAL_MODELS=true`
- Windows 下 npm 全局 `clawmem.CMD` shim 已自动经 `cmd /c` 启动

## 配置

`config.json`（`init` 生成，可手改）：

```json
{
  "clawmem_topic": "记忆宇宙计划",
  "clawmem_max_chars": 8000,
  "agent_dirs": { "dsh": "...", "hermes": "...", ... }
}
```

## 实测

- `python main.py write ...` → 本地 `F:\...\* -YYYYMMDD-HHMM-dsh.md` + clawmem diary 条目，均验证落盘。
- `bootstrap` 实测返回最新记录三段 + clawmem 5 条日记。
- 2026-10-05 于 Windows + Python 3.12 验证。
